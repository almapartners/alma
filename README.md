# ALMA Partners website

Plain HTML site, hosted on GitHub Pages. No build step.

- Pages: `index.html` (Home), `what-we-do.html`, `team.html`, `contact.html`
- Text: every line appears twice, once inside `data-l="ko"` (Korean) and once inside `data-l="en"` (English). Change both.
- Look: `css/style.css`. Behaviour (language switch, menu, scroll effects): `js/main.js`.
- Images: `assets/`.
- Contact form messages go to charlierhee@almapt.co.kr via formsubmit.co (change the address in `contact.html`).
